a section heading

A link, strong text, and code.

buttons

One type draws every action. Its weight is its constructor; bad, fill and a glyph qualify it.

compact

The compact size, for controls in a row or a toolbar: a field, a combo and a button at this size line up exactly. A compact class on a container compacts everything inside it.

requests

A request carries its URL as data, and the button is busy for exactly as long as its own request runs.

frame

The bar over an app's pages and the foot under them, each clear of a phone's notch and home indicator.

navigation

Tabs, cards and lists whose links load in place. One Navigation in the shell loads every link of a marked region in place, and Back and Forward with them.

asking first

A question, or the server's preview of a change, in the page's one Confirm. Yes waits for its own preview.

sheets

A dialog opened and closed through commandfor, with no script: rising from the bottom on a phone.

fields

A label leading, the control filling the width, and a note under it that describes the control.

choices

A box leading its words inline, or a settings row with the box where a switch would be, and a list of rows to tick and act on together.

forms

A form keeps its method and action, and its submit is busy while the form's request runs.

state

A status's word says what its colour does; a meter is named for a screen reader.

messages

A notice says something about the page in place; an empty state stands where a list would be.

content

Labelled pairs, a bulleted list of values, times in the reader's zone and counters of time spent or left, rendered Markdown, a disclosure that opens or loads, and a value to copy.

icons

The kōan set, on a 24-unit grid, its stroke set by the size it is drawn at.

classes

Containers whose markup is one element and a class stay classes: a component would only rename them.

panel

A region of the page on the lighter ground.
