{#- The page's one owner of the history. A plain click on a link inside a marked region, or on an in-place link anywhere, to this origin and not to a fragment of the page shown, reads its address in place; the pressed link is busy until the load settles, and the next press abandons it, since a request from this element cancels the last. Nothing is pushed until an answer sets the signal to the address it drew: once the load has settled, that address is what the page shows, pushed when the bar shows another, so a load that fails leaves the address alone. Back and Forward read the entry's address in place, unless the page already shows it or only the fragment moved; should that load fail, the entry is replaced with the address the page does show. Only the page's first navigation acts. -#}
