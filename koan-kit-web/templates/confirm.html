{#- The page's one sheet for asking before a change. A button that asks fills the `_kitconfirm` signals from its own data and opens it; the header closes it when a handler sets `open` false; the section aborts the last opening's preview request, empties itself, and fetches this opening's preview, if it has one; yes waits for `ready`, sends the button's request, and is busy while it runs, during which the sheet cannot be dismissed, so its answer cannot land on a later question. A handler's error shows inside the sheet, where a flash under the dimmed page would not be seen. A question asked by a button that sends a form posts that form's fields. Once a handler closes the sheet with `done`, the button that asked hears `kit-confirmed`. Busy is written as a string, since Datastar writes a bare `true` as an empty attribute. -#}
