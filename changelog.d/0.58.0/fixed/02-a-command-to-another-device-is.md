- **A command to another device is no longer taken as delivered when it was only queued** ([#870](https://github.com/radiosilence/koan/issues/870)). A device now answers each command once it has acted on it. With no answer the sender tries the next way through (the local network, the link, then one request to the server) with the same command id, and a device that gets it twice acts once. The server answers for a device that is away, once it has been woken to take the command, and takes a link that has sent nothing since the command for dead, dropping it and waking the device instead of waiting out the 100-second silence. Devices and servers that predate this are sent commands as before.
