- **kōan's apps can keep their queue on the server.** Off by default, Settings → Server → Keep the queue on the server keeps this device's queue in the account's saved play queue, so a queue started in Feishin, Symfonium or another Subsonic client can be picked up in kōan, and the reverse. Turning it on asks before replacing this device's queue with the server's. Edits are saved as they settle, a change of track or a pause with the playhead, and at launch the server's queue is taken only if another client saved it since ([#874](https://github.com/radiosilence/koan/issues/874)).
