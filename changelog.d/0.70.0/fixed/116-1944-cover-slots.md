- **A page's covers ahead of the cover preload.** The preload's requests no longer count against the limit a page's cover requests share, so a page never waits behind them or gives up on a slow connection; a `koanCovers` answer pauses while a page's covers load, and a preload waiting for a slot stops as soon as it is stopped or the app goes quiet. A kōan server reads a few covers ahead of the one it is sending.
