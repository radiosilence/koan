- **Covers kept on the device.** A cover fetched just before signing in to another server is kept under the server it came from, and a preload running when the server changes stops. Trimming the cache removes the covers least recently used and the oldest records' first, keeps the record of covers the server lacks, and no longer resets the queue's downloads when only covers went. Scrolling quickly no longer makes other cover requests give up. Clearing the apps' artwork, and a cover the Mac app could not decode, now reach the server again instead of the engine's kept copy.
