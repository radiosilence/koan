- **Release types.** Album tiles name a record's release type (EP, Single, Live), and artist pages group records under Albums, EPs & Singles, Live, Compilations and Other releases. Read from MusicBrainz release type tags or an OpenSubsonic server's `releaseTypes`; the next scan and sync read every file and album again to fill them in. Records are dated by their original release where it is tagged, so a reissue sits where the record does.
