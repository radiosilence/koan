- **Corrections and tunings add up as on squig.link.** A tuning's difference from the correction's target plays in full up to 6 kHz and fades out by 12 kHz, the range squig.link's Auto EQ works in, so a correction to neutral with a target's tuning on top comes close to a correction to that target. Measurements fetched from squig.link have the site's calibration subtracted, as the site does before drawing or equalising them, and the shipped Harman in-ear 2019 target is squig.link's file. AutoEQ corrections moved to another target are rebuilt from AutoEQ's measurement with the same fade, and sound different above about 6 kHz: by up to 3 dB on a Sennheiser HD 650. An in-ear correction moved to Harman in-ear 2019 also changes slightly with the new target file. A measurement fetched from squig.link (Super* Review) before this needs fetching again to pick up the calibration; `koan dsp measure` takes a file as it is, so a site's raw left or right file is not calibrated.
