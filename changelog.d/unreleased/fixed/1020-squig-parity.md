- **Corrections built from a measurement match squig.link's auto-EQ presets.** A correction now fades out between 6 and 12 kHz instead of being held to ±3 dB above 10 kHz, and a tuning's target difference fades with it, so a correction to neutral with a target's tuning on top equals a correction to that target. Measurements fetched from squig.link have the site's calibration subtracted, as the site does before drawing or equalising them, and the shipped Harman in-ear 2019 target is squig.link's file. Existing corrections built from a measurement sound different above about 6 kHz, and so do AutoEQ corrections moved to another target, which are rebuilt from AutoEQ's measurement the same way: by up to 3 dB on a Sennheiser HD 650 moved to another target. An in-ear correction moved to Harman in-ear 2019 also changes slightly with the new target file. A measurement fetched from squig.link (Super* Review) before this needs fetching again to pick up the calibration; `koan dsp measure` takes a file as it is, so a site's raw left or right file is not calibrated.
