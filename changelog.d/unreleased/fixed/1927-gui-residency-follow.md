- **Kept running, kōan leaves the Dock only once none of its windows is open.** Closing the main window with Settings still open no longer takes Settings out of the Dock and the app switcher; a launch at login stays in the menu bar whatever order the start-up reads land in; and keeping kōan running follows the configuration file as it is written, so a write that fails, or an edit made elsewhere, does not leave it acting otherwise.
