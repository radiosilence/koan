Forgetting several plays in a row in History forgets each one, and a failed read no longer stops the page following new plays. The EQ curve stays up while unrelated settings are written. A grey sleeve with a small coloured logo leaves the accent mint, an accent too dark to read as text colours only marks and bars, and turning record colours off or on applies at once. A cover missing from a file still downloading is read again once it arrives. Wide device names no longer overflow the output chooser, and the choosers and menus keep their scroll position while the cursor moves within view.
