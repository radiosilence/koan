- **Vendored GPUI as patches; development builds without Xcode.** Each vendored GPUI crate is its crates.io release plus `vendor/patches/<crate>.patch`, checked in CI; `just vendor-gpui VERSION` moves them to a new release and stops at a patch that no longer applies. The `runtime-shaders` feature, which the development recipes turn on, compiles GPUI's Metal shaders at startup, so the Command Line Tools are enough to build the GUI app.
