- **koan-core's decoder runs in the browser.** An experimental web client (`crates/koan-web`, `just web-client`) decodes a track from a koan server in a Web Worker and plays it through an AudioWorklet over shared memory, served by `koan serve` at `/client/` when `KOAN_WEB_CLIENT_DIR` is set. koan-core's SQLite, network and filesystem-watching parts move behind a default `native` feature so the rest builds for WebAssembly.
