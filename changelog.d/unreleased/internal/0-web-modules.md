- **The web UI's scripts are ES modules, and the player is a class.** `ui.ts` and `share.ts` import `Player` from `koan/player`, which an inline import map names at the player's versioned URL, so a cached old player is never paired with a new page script; the CSP allows the map by its hash. The player's state is private fields, and an explicit buffer-or-stream mode carries its audio context, so the types know when there is one.
