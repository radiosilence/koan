- **koan-server in modules, its SQL in koan-core.** The Subsonic API and the linked-client registry are split into a module per concern with their tests beside them, the response tree names its elements with an enum, and every query koan-server ran against koan-core's tables is a tested function in `koan_core::db::queries`. Devices are now told to sync when a rescan rewrites tags, not only when tracks or albums are added or removed.
