- **Sign-in fixes from a review of koan-auth.** Behind a proxy that appends a port or `unknown` to `X-Forwarded-For`, a client could choose the address its sign-in limits were counted against. Now only the proxy's own entry is read. Two admins removing each other at once, a password reset that failed part way, and deleting an account over a connection without foreign keys could each leave accounts in a state the rules forbid; each now runs in one transaction. API keys are looked up by digest instead of by scanning every key, a limit on OAuth redirect hosts now applies to clients registered before it was set, and the sign-in limiters no longer rescan their whole map on every request during a flood.
