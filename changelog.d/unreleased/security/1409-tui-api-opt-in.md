- **The TUI no longer serves the API unasked.** `koan` started the GraphQL/Subsonic API on 127.0.0.1:4000, and with no accounts any local process could claim it through `/setup`. It now serves only with `--api`, `--port`, `--bind`, `--subsonic` or `--playground`, or `[graphql] enabled = true`; set that to keep the old behaviour. Headless mode is unchanged.
