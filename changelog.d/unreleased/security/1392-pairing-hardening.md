- **Pairing guesses are limited, and undelivered keys revoked.** An account that looks up ten pairing codes in a minute that no device is waiting with is refused until the minute is out. A key approved for a device that never receives it, because its socket failed or it went as the approval arrived, is revoked, and a device that stops answering pings is dropped after 75 seconds instead of holding its pairing open for ten minutes. Looking a pairing up and declining it now need the same credentials as approving it: the account's own password or an API key.
