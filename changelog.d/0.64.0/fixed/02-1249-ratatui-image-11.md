- **Terminal UI: scrolling the album grid with cover graphics.** Covers out of view are now dropped least recently drawn first, instead of the whole set at once, so scrolling a long library no longer redraws and resends every visible cover. Dropped kitty covers are also deleted from the terminal, which kept them in its image memory until now. Over SSH covers are sent compressed where the terminal supports it, and kitty images now draw inside tmux. The minimum supported Rust version is 1.90.
