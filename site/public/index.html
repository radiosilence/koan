kōan

One music player for your own music, wherever you listen. It is a server, a desktop app, a phone app, an Apple TV app and a terminal player, all on one Rust core. It plays folders on your computer, a kōan server, or any OpenSubsonic server such as Navidrome.

Use it as everything

  • Server. koan --headless or the container image, on the machine with the music. A web UI with gapless playback, public share links, an OpenSubsonic API and MCP for assistants. It replaces Navidrome: how to move.
  • Desktop. macOS and Linux. Local folders, a server, or both merged into one library. On a Mac it can serve its library to your phone without a separate server.
  • Phone. iPhone and iPad through TestFlight, Android as an APK. Plays from a server, fetches the queue ahead and keeps what it plays, so it carries on with no signal.
  • TV. Apple TV, signed in from a phone with no password to type. Your phone or computer can play to it.
  • Terminal. koan on macOS and Linux: a full player, plus scanning, search, file organisation and the server, in one binary.
  • Other apps. Each part works alone. kōan's apps play from Navidrome, and Play:Sub or any other Subsonic app plays from a kōan server.

The new GPUI apps

The desktop app is drawn with GPUI, the GPU framework built for the Zed editor. It has been kōan's only app on the Mac since 0.70, and it runs on Linux too. There is no Electron and no web view, and it links the audio engine directly.

The moving parts are shaders: the colour wash from the record's sleeve, the playing bars, the seek bar, the lyrics and the answer to a press. It moves at the display's refresh rate, full screen on a 4K display holds 120 fps, and nothing is drawn while nothing moves.

The same app now runs on the iPhone, with four tabs, a mini player, Now Playing and touch throughout. It is with internal testers and not yet released; the iPhone app on TestFlight is the SwiftUI one.

What it does that others don't

  • Your DAC runs at the track's rate. The output switches to each track's sample rate, gapless and bit-perfect where the system allows, and the format badge says when it isn't.
  • Correction per output. AutoEQ, Equalizer APO, CamillaDSP, REW and Roon filters import as they are, each tied to a device. A device with no profile runs nothing. EQ and convolution.
  • Devices control each other. Any kōan app can drive another or move the music to it, and the other device plays its own copy. UPnP amps get the original file. Devices.
  • Inviting someone is one link. A link or QR code signs a device in with a key of its own. Invites.
  • An assistant can drive it. The server speaks MCP with its own sign-in, and can never move, rename or delete a file. MCP.

Not there yet: Windows, tag editing, crossfade, CarPlay, Chromecast, Sonos. How kōan compares goes through it feature by feature.

Install

Mac: Koan.dmg (macOS 26 or later on Apple silicon), or Homebrew:

brew install --cask radiosilence/tap/koan-app

Linux: each release has an AppImage and a .deb for x86-64 and ARM64.

iPhone, iPad and Apple TV: the TestFlight beta, iOS or tvOS 26 or later.

Android: sideload koan-android-arm64.apk on an arm64 phone running Android 10 or later.

Terminal:

mise use -g github:radiosilence/koan@latest
# or: brew install radiosilence/tap/koan
# or: cargo install koan-cli

Server: the container is below; Running a server has the rest, including the reverse proxy it expects.

docker run -d --name koan -p 4000:4000 \
  -v koan-config:/config \
  -v /path/to/music:/music:ro \
  -e 'KOAN_LIBRARY__FOLDERS=["/music"]' \
  -e 'KOAN_GRAPHQL__ALLOWED_HOSTS=["music.example.com"]' \
  -e KOAN_SERVER__URL=https://music.example.com \
  -e KOAN_SUBSONIC__ENABLED=true \
  ghcr.io/radiosilence/koan:latest

docker exec -it koan koan auth setup   # the admin account

No server yet? Sign in to demo.koan.rocks as demo, password demo, from any of the apps or a browser. It resets every day at midnight UTC. Getting started covers the first run.
